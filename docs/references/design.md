# Folio product and visual references

Primary materials reviewed 2026-11-14. These are reference products, not code/assets copied into Folio.

| Product | Reference | Adopted principle |
|---|---|---|
| here.now | https://here.now/docs | Agent publishes files/directories, stable URLs, revisions, custom domains, visible persistence/access state. Prior hands-on create/update experiment verified. |
| Vercel | https://vercel.com/docs/projects | Artifact/project-first library, useful thumbnails, deployment/version detail, domains close to the artifact. |
| Linear | https://linear.app/docs/workspaces | Compact persistent workspace navigation, clear separation of personal settings and admin controls. |
| Linear members | https://linear.app/docs/invite-members | Role-aware member management; Folio adapts invitation into direct admin creation for offline use. |
| Notion | https://www.notion.com/en-gb/help/sharing-and-permissions | General access switch, explicit people grants, clear difference between workspace and public-link access. Folio uses a full-height right drawer. |
| Notion sharing guide | https://www.notion.com/en-gb/help/guides/understanding-notions-sharing-settings | Show who can access before copying a link; never conflate link possession with permission. |
| Supabase | https://supabase.com/docs/guides/platform/custom-domains | Stepwise DNS setup with actual verification state, copyable records, useful failure diagnostics. |
| Dropbox | https://help.dropbox.com/share/set-file-folder-permissions | Separate selected people, team, and anyone-with-link modes; member list makes access concrete. |
| Cloudflare Tunnel | https://developers.cloudflare.com/tunnel/get-started/ | DNS and origin reachability are distinct steps; surface connector health separately from record status. |

## Visual direction
Warm ivory canvas, subtle sage navigation, forest-green accent, charcoal body type, thin separators. The artifact is the visual subject: no decorative KPI cards. Serif wordmark/editorial page headings and crisp system sans for dense interface text, Korean system fonts without remote loading. Desktop app shell, real artifact preview tiles, right sharing drawer; mobile collapses navigation and drawer to accessible full-screen sheets.

`assets/folio-library-concept.png` is an AI-generated design blueprint, created with the built-in image_gen tool after 12ui's hosted draft was unavailable without a separate account. It is not a screenshot of a functioning product. Final implementation must use actual server data and uploaded artifact previews, not the blueprint's fictional metrics/member identities.

Prompt: high-fidelity Folio desktop workspace; Linear shell precision, Notion sharing, Vercel artifact thumbnails, Supabase settings clarity; ivory/sage/forest palette; artifact library with personal/organization collections; right-side sharing with selected-member picker and expiry; accessible, responsive, mature product density, no fake dashboards or neon/purple gradients.
