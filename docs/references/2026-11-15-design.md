# Workspace redesign references

Inspected 2026-11-15; implementation baseline `origin/main @426755e`. The user approved composition B, a light file-browser workspace, after rejecting the original visual identity. Generated concepts are private research artifacts, never shipped as product screenshots.

- [Figma file browser](https://help.figma.com/hc/en-us/articles/14381406380183-Guide-to-the-file-browser): clear account, scope and file navigation. [Official April 2025 file-card update](https://forum.figma.com/product-updates-3/updates-announced-on-the-april-25-release-notes-livestream-39496): large preview above a shallow title and metadata area.
- [Vercel dashboard navigation, February 2026](https://vercel.com/changelog/dashboard-navigation-redesign-rollout): separated workspace navigation and consistent context. Applied as one sidebar hierarchy with a slim breadcrumb row; duplicate collection tabs removed.
- [Linear projects](https://linear.app/docs/projects): readable properties and document details. Applied to artifact inspector and version rows.
- [Resend bulk actions](https://resend.com/changelog/bulk-actions): restrained table controls and explicit actions. Applied to administration and list surfaces.
- [Pretendard](https://github.com/orioncactus/pretendard): bundled variable font with Korean/Latin coverage. Its SIL OFL license is retained in the font directories and release archives.

The existing source contracts were checked directly in `web/src/App.tsx`, `Artifacts.tsx`, `Admin.tsx`, `Auth.tsx`, `ui.tsx`, `types.ts`, `docs/API.md` and the browser acceptance suite. Existing API calls, modal focus behavior, authorization gates and content iframe sandbox/origins are preserved. The four-option sharing picker replaces the select control while submitting the same `visibility`, `memberIds` and `expiresAt` payload.

Reference screenshots remain private research material. Production previews use the actual installed artifact iframe. The public tour is an authored static artifact with an explicitly labeled local visibility simulation; it does not present mock collaborators, storage health or analytics as installation data.

Mobile navigation follows the [WAI modal-dialog focus pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/): enter focus, contain Tab/Shift+Tab, Escape/visible close and restore focus. Closed mobile navigation and the covered canvas use the [HTML inert attribute](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/inert). Its Boolean React attribute was verified in the installed `@types/react/index.d.ts`; keyboard behavior is asserted in the actual browser acceptance suite.
