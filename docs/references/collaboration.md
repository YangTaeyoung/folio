Dependency source was also inspected directly during implementation:

- `golang.org/x/crypto@v0.59.0/scrypt/scrypt.go:177-195` documents the key-size/cost inputs used by Folio.
- Go 1.26 `src/crypto/cipher/gcm.go:30` defines `NewGCM`; its `AEAD` contract supplies authenticated encryption/decryption.
- Go 1.26 `src/net/http/cookie.go:26` defines the cookie fields used by the guest flow.
- Go 1.26 `src/archive/zip/reader.go:218` defines entry opening; Folio adds application-level path, entry-count, method and expanded-byte validation.

These primitives do not themselves define Folio's trust policy. [feature_types.go:70](../../internal/server/feature_types.go#L70) enforces version permission; [server.go:534](../../internal/server/server.go#L534) enforces artifact permission; [content.go:135](../../internal/server/content.go#L135) rechecks grants and requested assets. Guest links are a separate explicit version grant and never change ordinary anonymous visibility.

Focused recovery tests cover wrong passwords, ciphertext modification/truncation, unsafe/compressed ZIP entries, actual restored bytes under new local keys, active-upload exclusion, and remote-object snapshots with no writes/deletes to the remote source. Guest tests exercise the full management/content handlers with a signed-in browser, exact-version boundaries and revocation of an existing viewer. [ops_test.go](../../internal/server/ops_test.go) contains the executable cases. These local tests do not claim a production deployment or a live cloud-provider account validation.
