From a folder to a shared artifact.

Start with an index.html and its assets. Publish privately, inspect the result, then apply the audience you actually want.

  • Uses your scoped API token
  • Supports revisions and rollback
  • No model subscription required by Folio
Full agent setup 
# After private login and token setup
folio publish --title "Project preview" ./site

# Share only when you choose
folio share --visibility organization ARTIFACT_ID

Replace ARTIFACT_ID with the published artifact ID.
